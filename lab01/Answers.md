1. **Why do we use Kali Linux?**  
We use Kali Linux because it is a Linux distribution made specifically for penetration testing, security auditing, forensics, reverse engineering, and vulnerability detection. It is built for security work rather than for everyday desktop use.

2. **What is the advantage of Kali Linux compared to other Linux distributions?**  
Its main advantage is that it comes preconfigured for security testing: it includes several hundred security tools, configurations, and scripts, has network services disabled by default, uses a kernel patched for wireless injection, and is available on many platforms. Kali is specialized for cybersecurity work.

3. **Which features and tools of Kali Linux attracted you the most?**  
The most attractive features are the large built-in toolset and the fact that everything is in one place. The tools that stand out most are Nmap, Wireshark, Burp Suite, Metasploit, Aircrack-ng, SQLMap, Hydra, and John the Ripper.
